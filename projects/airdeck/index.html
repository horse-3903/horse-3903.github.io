// how it works
01 Server

A Qt app that listens on one port

Built in C++ with Qt 6. It takes each phone's input and turns it into a virtual Xbox 360 controller through ViGEm, a Windows gamepad, or keyboard and mouse. Up to six controllers, each with its own colour, and a page that tests every stick and button live.

C++Qt 6ViGEmWindows
02 Android app

A controller you can rebuild

Kotlin and Jetpack Compose. Sticks snap to your thumb, the D-pad can hold diagonals, and every control can be moved or resized. Haptic strength and length are adjustable, and a foreground service keeps the connection alive with the screen off.

KotlinJetpack ComposeAndroidDataStore
03 Browser controller

No install, any phone

One HTML file served by the same port, with the same layout as the app. It works on Android and iPhone, reconnects by itself, and reloads when the server has a newer version. On iPhone, Apple's web API only offers basic timed pulses, so haptics there are not the Taptic Engine feel the app can give on Android.
